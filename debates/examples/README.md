# Debate Examples

这些示例不是可安装 skill，而是帮助使用者理解各领域 `cogd-*` 可以处理什么样的具体话题。

| 示例话题 | 推荐入口 |
| --- | --- |
| 人生应该追求意义、幸福、自由，还是责任？ | `cogd-life` |
| 自我实现和对他人的承诺发生冲突时怎么办？ | `cogd-life` |
| AI 增强人的能动性，还是削弱判断和责任？ | `cogd-technology` |
| 软件架构中的秩序来自原则、分类、演化，还是实践？ | `cogd-engineering` |
| 工作应该服务意义、能力、财富，还是自由？ | `cogd-work` |
| 真实、有效、叙事和工具性之间如何取舍？ | `cogd-knowledge` |
| 自由、纪律、习惯和创造力之间如何冲突？ | `cogd-work` |
| 教育是塑造、保护、放手，还是筛选？ | `cogd-learning` |
| 技术进步带来的收益、代价和不可逆损失如何判断？ | `cogd-technology` |
| 专家判断、公众参与、权力和责任边界如何划分？ | `cogd-governance` |

新增示例时，不要新增 `SKILL.md`。只有当一个方向稳定成为领域能力时，才在 `debates/<domain>/SKILL.md` 下新增入口。
