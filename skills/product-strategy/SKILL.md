# Product Strategy

这是 ArchSight Cognition 的公共发现入口，用于评审产品方向、定位和最小验证。内部对应 `cogt-product`、`cogx-prd`、`cogx-strategy-brief`、`cogp-christensen`、`cogp-drucker`、`cogm-business-logic` 和 `cogm-priority-triage`。

## When To Use

用户要求评审产品方向、用户问题、定位、增长假设、MVP、市场进入、差异化和商业模式时使用。

## Method

1. 明确目标用户、用户问题和替代方案。
2. 检查定位、差异化、商业约束和增长假设。
3. 拆出最小可验证假设和不要做清单。
4. 给出 MVP 范围、验证实验和停止条件。

## Output

默认使用用户的主要语言输出；中文请求使用下面的中文标题，英文请求可自然翻译为英文标题。

```text
用户问题:
目标用户:
定位:
差异化:
关键假设:
MVP 范围:
验证方式:
停止条件:
```

## Guardrails

- 不要用愿景替代用户问题。
- 不要把竞品或市场事实当作未检索常识。
- 不要把 MVP 扩写成路线图。
