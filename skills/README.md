# Public Skill Entry Points

`skills/` 是面向公共 skill 市场、`skills.sh`、Gemini CLI extension 和 Claude Code plugin marketplace 的任务型入口。

本目录不替代 `personas/`、`methods/`、`teams/`、`deliverables/`、`voices/` 和 `debates/`，而是把最容易被外部用户搜索的 job-to-be-done 包装成标准 `SKILL.md`：

- `architecture-review`：架构评审、边界、耦合、演化成本和技术债。
- `structured-thinking`：问题澄清、认知路由、概念边界和下一步判断。
- `multi-perspective-review`：跨学科、多视角、team panel、综合评审。
- `structured-debate`：结构化分歧、长期议题、价值冲突和立场压力测试。
- `decision-review`：决策分析、风险、反对条件和下一步验证。
- `writing-review`：写作、论证、叙事、风格和表达诚实性。
- `design-review`：产品体验、视觉、交互、信息架构和界面层级。
- `product-strategy`：用户问题、产品定位、差异化、市场进入和最小验证。
- `engineering-leadership`：研发组织、技术路线、质量债、激励和交付反馈。
- `prd-writing`：PRD、产品需求、验收标准和发布风险。
- `research-synthesis`：调研综合、来源质量、分歧和证据强度。
- `strategy-review`：战略分析、市场进入、取舍和最小行动。
- `critical-thinking`：论证、前提、证据、谬误和结论强度。
- `chinese-thinking`：中国思想、中文叙事、中国组织语境和传统/现代分歧。

内部长期维护仍以 `cogt-*`、`cogm-*`、`cogx-*` 等原始工具为准；本目录优先服务公共检索、快速试用和跨 host 安装。
