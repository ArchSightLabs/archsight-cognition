# Strategy Review

这是 ArchSight Cognition 的公共发现入口，用于评审战略方向、市场进入、定位、资源分配和最小行动。内部对应 `cogx-strategy-brief`、`cogt-product`、`cogt-decide`、`cogm-business-logic` 和 `cogm-tail-risk`。

## When To Use

用户要求评审战略、定位、增长方向、市场进入、竞争风险、资源配置、长期取舍或组织执行路径时使用。

## Method

1. 复述战略目标、约束和成功标准。
2. 标出用户、市场、竞争、资源、组织和时间窗口。
3. 检查差异化是否真实、关键假设是否可验证、失败代价是否可承受。
4. 给出最小行动、反对条件和复盘点。

## Output

```text
Strategic goal:
Context:
Assumptions:
Differentiation:
Risks:
Trade-offs:
Minimum viable action:
Rejection conditions:
Review cadence:
```

## Guardrails

- 不要用宏大叙事替代可执行动作。
- 不要把愿景写成已经成立的市场事实。
- 涉及当前市场、竞品、政策、价格、融资或新闻时，必须检索或标注待验证。
