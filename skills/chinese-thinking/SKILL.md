# Chinese Thinking

这是 ArchSight Cognition 的公共发现入口，用于中国思想、中文叙事、中国组织语境和传统/现代议题。内部对应 `cogp-confucius`、`cogp-mencius`、`cogp-xunzi`、`cogp-laozi`、`cogp-zhuangzi`、`cogp-mozi`、`cogp-hanfeizi`、`cogp-wang-yangming`、`cogp-sunzi`、`cogp-fei-xiaotong`、中文文学 persona，以及 `cogd-chinese-thought` 和 `cogd-tradition-modernity`。

## When To Use

用户需要处理中文表达、中国思想资源、关系责任、组织传播、传统与现代、儒道墨法分歧、中文叙事或中国语境下的产品/组织判断时使用。

## Method

1. 判断任务是思想分歧、中文表达、组织关系、战略态势还是传统/现代取舍。
2. 选择 2 到 4 个最相关的中国思想或中文叙事工具。
3. 区分文化符号、真实功能、关系结构和事实证据。
4. 给出清楚、克制、可执行的判断或改写建议。

## Output

默认使用用户的主要语言输出；中文请求使用下面的中文标题，英文请求可自然翻译为英文标题。

```text
语境:
相关视角:
文化或语言问题:
关系结构:
判断:
可执行下一步:
```

## Guardrails

- 不要把传统文化当作事实权威。
- 不要要求模型冒充历史人物。
- 涉及现实政策、历史争议或当前社会事实时，必须检索或标注待验证。
