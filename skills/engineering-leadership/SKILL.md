# Engineering Leadership

这是 ArchSight Cognition 的公共发现入口，用于技术领导、研发管理和组织交付评审。内部对应 `cogt-lead`、`cogp-grove`、`cogp-drucker`、`cogp-simon`、`cogm-management-hygiene`、`cogm-operating-principles` 和 `cogm-tail-risk`。

## When To Use

用户要求分析研发组织、技术路线、质量债、团队激励、执行节奏、管理杠杆、交付反馈或技术管理问题时使用。

## Method

1. 明确组织目标、交付压力和当前症状。
2. 区分技术问题、流程问题、激励问题和管理边界问题。
3. 检查质量债、反馈回路、会议/授权卫生和责任边界。
4. 给出最小管理动作、复盘指标和风险。

## Output

默认使用用户的主要语言输出；中文请求使用下面的中文标题，英文请求可自然翻译为英文标题。

```text
领导力问题:
症状:
根因力量:
技术债:
运营风险:
管理杠杆:
建议行动:
复盘指标:
```

## Guardrails

- 不要把所有组织问题都归因于个人能力。
- 不要用流程替代责任。
- 涉及真实组织事实时，要区分用户提供事实和推断。
