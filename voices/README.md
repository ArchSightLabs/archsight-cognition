# Voices

`voices/` 存放 `cogv-*` 风格化口吻工具。

`cog-*` 是认知工具，用于分析、审查和判断。`cogv-*` 是 cognition voice 工具，用于用某种思想气质、语气、节奏和修辞方式表达，但不声称历史人物本人在说话。

## 规则

- `cogv-*` 可以模仿表达气质、论证姿态、节奏和关注点。
- `cogv-*` 不替代 `cog-*` 的严肃分析。
- 不要声称“本人会这样说”。
- 涉及事实、法律、医疗、金融和现实人物时，仍需要检索或专业来源。

## 命名

```text
cog-kant    康德式原则审查
cogv-kant   康德式口吻表达
```
