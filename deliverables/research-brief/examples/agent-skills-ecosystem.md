## Expected Shape

- Restates the research question and decision use.

- Lists sources such as Agent Skills standard, Anthropic skills, Fabric, SuperClaude, LangChain DeepAgents, GitHub Copilot Agent Skills, and relevant marketplaces.
- Separates facts from inferences.
- Identifies what ArchSight can borrow from each reference.
