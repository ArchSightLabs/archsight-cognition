# Example: Chinese Agent Skills Open Source Plan

## Prompt

```text
/cogx-research-plan
我想研究 AI agent skills 这个方向，看它有没有机会做一个中文开源项目。
```

## Expected Shape

- Defines the research purpose and decision the plan should support.
- Separates ecosystem facts, user needs, competitor structure, distribution channels, and risk assumptions.
- If the host has retrieval tools, performs minimum search and lists sources; otherwise lists a search plan.
- Gives interview questions, priority validation order, timeline, deliverables, stop condition, and risks.
- Does not treat stars, search heat, or marketplace listings as direct proof of demand.
