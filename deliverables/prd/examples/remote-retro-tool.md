# Example: Remote Team Retro Tool PRD

## Prompt

```text
/cogx-prd
我们想做一个给远程研发团队用的 AI 复盘工具。它会自动整理会议、提取问题、生成改进建议。
```

## Expected Shape

- Narrows the target user and use case instead of writing a broad platform PRD.
- Distinguishes meeting summarization from changing delivery behavior.
- Lists assumptions and external facts that need validation.
- Defines MVP scope, non-goals, minimum validation experiment, stop condition, and next-week tasks.
- Does not claim market demand without evidence.
