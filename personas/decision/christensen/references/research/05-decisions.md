# Christensen 05 - 关键决策与行动模式

调研日期：2026-05-27

## 研究目标

提取 Christensen 在研究路线和理论建构中的行动模式，用于构造创新判断工具。

## 关键行动模式

1. 从磁盘驱动器行业进入创新理论
   - 背景：技术性能提升和企业失败之间存在反直觉关系。
   - 行动：研究硬盘产业变迁，解释为什么优秀公司会错过新技术路径。
   - 可迁移模型：不要只问公司是否聪明，要问资源配置和价值网络如何塑造行动。

2. 把“颠覆技术”扩展为“颠覆式创新”
   - 背景：技术本身并不自动产生颠覆，商业模式和市场入口才决定路径。
   - 行动：从技术属性转向创新过程、客户结构和商业模式。
   - 可迁移模型：新产品是否颠覆，取决于它如何进入市场并向上移动。

3. 将理论转为增长业务设计
   - 背景：管理者需要知道如何构造新增长，而不只是解释失败。
   - 行动：通过 *The Innovator's Solution* 等著作提出商业模式、组织承载和预测框架。
   - 可迁移模型：新业务应检查价值主张、资源、流程和利润公式是否一致。

4. 推广 Jobs to Be Done
   - 背景：按人口画像和产品属性理解用户选择，经常无法解释真实购买。
   - 行动：将创新起点转向用户在情境中要取得的进步。
   - 可迁移模型：产品定位先问用户任务，再谈功能和人群标签。

5. 主动澄清理论误用
   - 背景：Disruption 成为商业流行词后，概念边界被稀释。
   - 行动：与合作者重申颠覆式创新不等于任何突破技术或快速增长。
   - 可迁移模型：正式工具必须内置误用警报和反对条件。

## ArchSight 转换规则

- 先问用户任务，再问产品功能。
- 先判断入口类型，再使用“颠覆”一词。
- 先分析价值网络，再判断 incumbent 是否会反击。
- 先检查商业模式，再建议增长策略。
- 先列反对条件，再给创新判断。

## 不可直接迁移之处

Christensen 的案例和理论来自特定行业历史与商业研究传统。ArchSight 只迁移创新判断结构，不把案例结论自动套用到当代 AI、企业软件或中国市场。
