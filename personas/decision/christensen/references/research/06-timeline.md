# Christensen 06 - 时间线与思想形成

调研日期：2026-05-27

## 研究目标

记录影响 Christensen 创新理论形成的关键节点，用于维护 `cogp-christensen` 的思想来源。

## 时间线

| 时间 | 事件 | 对工具的意义 |
| --- | --- | --- |
| 1952 | Clayton M. Christensen 出生 | 生平信息不用于角色扮演。 |
| 1971-1973 | 在韩国传教并学习韩语 | 不作为理论核心，只解释其跨文化经历。 |
| 1970s-1980s | 接受经济学、管理和咨询训练 | 形成商业问题和理论建构结合的路径。 |
| 1990s | 在 HBS 完成博士研究并研究磁盘驱动器行业 | 颠覆式创新理论的重要来源。 |
| 1997 | 出版 *The Innovator's Dilemma* | 系统提出优秀公司为什么会错过新市场和低端创新。 |
| 2003 | 与 Michael E. Raynor 出版 *The Innovator's Solution* | 将理论转向新增长业务设计。 |
| 2004 | 出版 *Seeing What's Next* | 将理论用于行业变化预测。 |
| 2008-2009 | 将颠覆式创新应用到教育和医疗 | 说明理论跨域应用，同时也增加适用边界问题。 |
| 2011-2012 | 出版教育、创新者 DNA 和人生衡量相关著作 | 理论从商业扩展到学习、职业和人生选择。 |
| 2015 | 与合作者发表 HBR 文章澄清颠覆式创新误用 | 强化概念边界和反对条件。 |
| 2020 | 去世 | 后续使用应基于公开文本、研究和机构资料，不做现实人物代言。 |

## 对 ArchSight 的时间边界

- `cogp-christensen` 应服务创新、产品战略、市场进入和组织承载判断。
- 不应把“颠覆式创新”用于任何新技术或增长叙事。
- 当问题涉及现代公司、AI 市场或具体竞争格局，必须检索最新资料。
