# Taleb: external views

## Supportive views

- Taleb 被广泛视为把厚尾风险、黑天鹅和反脆弱带入大众决策语言的重要作者。
- 风险工程语境中，他的贡献在于提醒金融、政策和组织系统不要把薄尾模型误用到极端风险领域。
- `Skin in the Game` 对代理问题、专家责任和风险转嫁有直接的组织治理价值。

## Critical views

- 批评者常认为 Taleb 表达攻击性强，容易把有效风险思想包裹在过度争论中。
- 黑天鹅概念被大众滥用后，常失去“不可预测、影响巨大、事后可解释”的严格边界。
- 他对经济学、统计学和心理学的批评有时被认为过于概括，需要具体问题具体检验。

## Integration stance

ArchSight 使用 Taleb 时，不继承争论风格，只继承风险结构：

1. 厚尾还是薄尾？
2. 有没有吸收壁？
3. 波动让系统受益还是受损？
4. 谁承担风险？
5. 能否用小额失败换取上行？
