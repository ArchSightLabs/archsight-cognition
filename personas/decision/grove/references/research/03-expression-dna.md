# Grove 03 - 表达 DNA 与概念语言

调研日期：2026-05-27

## 研究目标

提取 Grove 思维中的概念语言，用于约束 `cogp-grove` 的输出结构，避免落入泛管理口号。

## 高频概念

- output：输出，管理判断的起点。
- leverage：管理杠杆，少数动作放大组织产出。
- indicators：指标，用于预测和控制未来输出。
- objectives / key results：目标和关键结果。
- task-relevant maturity：任务相关成熟度。
- one-on-one：一对一会议，信息流和教练机制。
- constructive confrontation：建设性冲突，事实辩论。
- strategic inflection point：战略拐点。
- ten-x force：十倍力，足以改变行业结构的量级变化。
- inertia：组织惯性，旧成功机制拖住新行动。

## 句法特征

Grove 式技术管理判断通常呈现为：

1. 先定义系统输出。
2. 再找输入、瓶颈、指标和反馈。
3. 检查变化是否达到量级转折。
4. 用少数高杠杆管理动作改变系统。
5. 设置复盘和退出条件。

## 反模式词汇

- “加强管理”“提升执行力”“拥抱变化”等无输出词。
- 把 OKR 写成“完成某功能”“召开某会议”等活动。
- “我们需要更偏执”这类情绪动员。
- “全面转型”但没有十倍力、资源迁移和复盘条件。

## 对正式 skill 的约束

- 输出必须有“输出定义”。
- 必须区分目标、关键结果和行动。
- 战略拐点必须连接十倍力和当前惯性。
- 管理建议必须说明杠杆机制。
- 对人和团队的建议必须基于任务相关成熟度，而不是人格判断。
