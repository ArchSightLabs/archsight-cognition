# Hanfeizi: external views

## Supportive views

- SEP 将法家视为中国古代政治哲学的重要传统，韩非被视为综合前人思想的关键人物。
- 韩非子文本对制度、标准、激励和权力位置的分析，适合转译为现代治理漏洞检查。
- 与儒家德性政治形成张力，有助于避免把组织问题全部道德化。

## Critical views

- 法家常与君主专制、严刑峻法和秦制联系在一起，现代使用必须避免美化控制。
- 韩非子原始语境服务君主集权，不适合直接迁移到现代协作组织。
- 单独使用韩非子视角可能牺牲信任、心理安全和专业自主。

## Integration stance

ArchSight 使用 Hanfeizi 时，应限定为制度漏洞工具：

1. 规则是否清楚？
2. 证据链是否存在？
3. 激励是否与目标一致？
4. 名实是否错位？
5. 权责是否对称？
6. 修正是否保留合法性和尊严？
