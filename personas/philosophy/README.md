# 哲学 Personas

每个哲学 persona 都是一个可独立加载的 `SKILL.md`。它们不是哲学家 cosplay，而是不同类型的判断工具。

推荐调用顺序：

1. `cogp-socrates`：先问清楚问题。
2. `cogp-wittgenstein`：清理概念和语言。
3. `cogp-aristotle`：分类、定目标、定判断框架。
4. 按需要调用其他人格施加判断压力。

快速映射：

| 问题类型 | 优先 Agent |
| --- | --- |
| 我是不是问错了问题 | Socrates |
| 这个概念是不是混乱 | Wittgenstein |
| 如何分类和落到实践 | Aristotle |
| 是否符合原则和边界 | Kant |
| 是否只是从众或软弱 | Nietzsche |
| 欲望和痛苦是否被低估 | Schopenhauer |
| 还能怀疑什么 | Descartes |
| 矛盾会如何演化 | Hegel |
| 无意义时如何行动 | Camus |
| 理想型与现实偏差如何分析 | Plato |
| 关系中的角色和责任是否清楚 | Confucius |
| 决策是否有正当性和人心基础 | Mencius |
| 行为是否需要训练、环境和制度化习惯 | Xunzi |
| 是否过度干预或过度设计 | Laozi |
| 是否被僵化分类和身份执念锁住 | Zhuangzi |
| 知道的判断是否进入行动和反馈 | Wang Yangming |
| 是否有实际功用、节用和公共利益 | Mozi |
| 制度是否过度依赖个人德性 | Hanfeizi |

## 中国思想工具

新增中国思想 persona 仍然遵守本仓库原则：不是历史人物模拟，而是可调用的判断工具。

- `cogp-confucius`：关系秩序、名实一致、角色责任和信任修复。
- `cogp-mencius`：人性假设、义利关系、正当性和长期信任。
- `cogp-xunzi`：人性假设、环境塑造、训练纪律、礼法结合和长期习惯。
- `cogp-laozi`：最小干预、系统反作用、删减控制和顺势。
- `cogp-zhuangzi`：视角切换、解除伪问题和打破单一尺度。
- `cogp-wang-yangming`：知行合一、现场验证和责任内化。
- `cogp-mozi`：功用、节用、公共利益、反浪费和工程伦理。
- `cogp-hanfeizi`：制度、激励、规则漏洞和执行闭环。
