# 哲学 Personas

每个哲学 persona 都是一个可独立加载的 `SKILL.md`。它们不是哲学家 cosplay，而是不同类型的判断工具。

推荐调用顺序：

1. `socrates`：先问清楚问题。
2. `wittgenstein`：清理概念和语言。
3. `aristotle`：分类、定目标、定判断框架。
4. 按需要调用其他人格施加判断压力。

快速映射：

| 问题类型 | 优先 Agent |
| --- | --- |
| 我是不是问错了问题 | Socrates |
| 这个概念是不是混乱 | Wittgenstein |
| 如何分类和落到实践 | Aristotle |
| 是否符合原则和边界 | Kant |
| 是否只是从众或软弱 | Nietzsche |
| 欲望和痛苦是否被低估 | Schopenhauer |
| 还能怀疑什么 | Descartes |
| 矛盾会如何演化 | Hegel |
| 无意义时如何行动 | Camus |
| 理想型与现实偏差如何分析 | Plato |
