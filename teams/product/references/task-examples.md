# Product task examples

## 用户问题澄清

```text
输入:
我想做一个面向工程师的 AI 知识管理产品，应该从哪里切入？

期望输出:
- 明确首批用户和场景。
- 拆出核心假设和证据缺口。
- 判断用户当前替代方案。
- 给出 1 个最小验证实验和停止条件。
```

## 定位和差异化

```text
输入:
我们和 Notion、Obsidian、飞书文档都有关联，怎么讲差异化？

期望输出:
- 用 Shannon 提炼核心信号。
- 用 Rams 删除泛化卖点。
- 用 Munger 逆向检查差异化是否只是形容词。
- 输出用户选择理由，而不是品牌口号。
```

## MVP 验证

```text
输入:
我们想先做插件、网页端和团队空间，哪个先做？

期望输出:
- 用 Simon 判断资源约束和满意解。
- 用 Bayes 选信息量最大的实验。
- 用 Norman 检查最短任务路径。
- 明确通过标准和停止条件。
```

## 增长与留存

```text
输入:
活跃下降，团队想加提醒、积分和活动。

期望输出:
- 用 Meadows 区分留存库存和拉活流量。
- 用 Taleb 检查提醒疲劳和信任损耗。
- 用 Drucker 回到外部结果。
- 给小实验，而不是增长动作列表。
```
