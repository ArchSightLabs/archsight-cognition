# Tech lead task examples

## 交付变慢

```text
输入:
研发团队交付越来越慢，大家都说是技术债太重，我该怎么处理？

期望输出:
- 区分技术债、流程延迟、激励扭曲、沟通失真和能力缺口。
- 找一个最小管理动作。
- 指定负责人、验证指标和复盘时间。
- 避免直接升级成大重构。
```

## 自动化边界

```text
输入:
能不能让 agent 自动评审所有 PR 并决定是否合并？

期望输出:
- 用 Turing 区分可机械检查、可辅助评分和人类责任判断。
- 用 Godel 检查规则完备性声称。
- 用 Shannon 检查反馈和报告格式。
- 给停机条件和人工回退路径。
```

## 研发组织调整

```text
输入:
我们想把平台团队拆成多个业务小组，提高响应速度。

期望输出:
- 用 Drucker 明确外部结果。
- 用 Weber 检查责任和权威边界。
- 用 Meadows 检查反馈延迟和副作用。
- 用 Taleb 设计低风险试点，而不是一次性重组。
```

## 协作失真

```text
输入:
产品、设计、研发经常互相误解需求，会议越来越多但问题没变少。

期望输出:
- 用 Shannon 找信号、噪声和编码问题。
- 用 Hanfeizi 检查规则漏洞和激励扭曲。
- 用 Kahneman 检查归因偏差。
- 输出一个减少会议但增强反馈的协作动作。
```
