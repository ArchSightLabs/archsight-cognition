# cogp 单视角命令演示案例

`cogp-*` 是单个学科或方法视角。它适合在问题已经有大致方向时，集中用一个镜头做澄清、压力测试或改写前判断。不要把它当成历史人物角色扮演；它只调用对应的思维工具。

使用方式示例：

```text
/cogp-bayes
我们准备把一个小样本用户访谈结论写进产品路线图，请检查证据强度。
```

## 本轮实跑示例

输入：

```text
/cogp-newton
一个 8 人远程团队每次产品发布都延期。大家说原因是沟通不好，但每次补会议后还是延期。请从变量、约束和系统建模角度检查。
```

结果：

```text
系统对象: 远程团队的发布流程，不是单次会议质量。
关键变量: 需求冻结时间、评审等待时间、返工率、测试进入时间、负责人切换次数。
主要约束: 跨时区响应慢、验收标准晚出现、测试资源集中在发布前。
作用力: 新需求持续进入推动延期；临近发布的质量压力推动返工；补会议只增加同步成本。
惯性: 团队习惯把延期解释成沟通问题，因此继续加会议，没有改变工作进入和退出条件。
可验证判断: 如果先冻结需求和提前验收标准，延期应下降；如果只加会议，延期不会稳定下降。
下一步: 记录两周内每个需求从提出到验收的等待时间，先改最长等待环节。
```
