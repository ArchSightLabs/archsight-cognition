# cogv 口吻命令演示案例

`cogv-*` 只负责风格化表达，不负责严肃分析结论。它适合在事实、判断和边界已经清楚后，把一段话改成更稳定的表达气质。不要要求它冒充历史人物本人，也不要伪造引文。

使用方式示例：

```text
/cogv-orwell
把这句产品公告改得更清楚：我们将持续赋能客户构建智能化增长闭环。
```

## 本轮实跑示例

输入：

```text
/cogv-orwell
把这句对外公告改得清楚一点：我们将持续赋能客户构建智能化增长闭环。
```

结果：

```text
风格化回应:
我们会把新的自动分析功能开放给客户，帮助他们更快发现销售线索、跟进进度和流失风险。

核心判断:
原句的问题不是不够高级，而是没人知道“赋能”“智能化”“增长闭环”分别指什么。

不应误读为:
这不是降低专业度，而是把责任从口号拉回到具体功能和具体用户结果。
```
